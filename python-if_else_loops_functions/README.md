## 📖 About this project

This is where plain scripts turn into *programs*. The project drills the three
building blocks every piece of logic is made of: branching with `if` / `elif` /
`else`, repetition with `while` and `for` (plus `range()` and `break`), and
packaging it all into reusable `def` functions with clean `return` values.

It's also the project where Python's most famous quirk becomes a feature:
**indentation is the syntax.** There are no braces here — a wrong indent is a
wrong program. Along the way the tasks sneak in character math with `ord()` /
`chr()`, nested loops for number combinations, and the classic FizzBuzz.

## 🎯 Concepts covered

- `if` / `elif` / `else` branching
- `while` and `for` loops, `range()`, `break`
- Defining functions with `def`, returning values with `return`
- Indentation as syntax — Python's whitespace rules
- String traversal and `ord()` / `chr()` character math
- Nested loops: printing number combinations in ascending order
- `print()` vs `sys.stdout.write()` — the newline question
