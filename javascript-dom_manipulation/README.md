## 📖 About this project

Now JavaScript returns to the browser — but this time *it* drives the
page, not the other way around. Each task pairs a `N-main.html` page with a
`N-script.js` that finds an element, changes its text, style or classes,
and wires up **event listeners** so the page reacts to clicks and typing.

It's the vocabulary of every frontend framework compressed into vanilla
JS: `document.querySelector`, `addEventListener`, `classList`,
`textContent`, `style` — the primitives React and friends are built on.

## 🎯 Concepts covered

- `document.querySelector` / `querySelectorAll` — finding nodes
- `addEventListener` — clicks, input, hover
- `textContent` vs `innerHTML` — safe vs powerful
- `style` and `classList` — restyling without reloads
- Event objects: `target`, `key`, coordinates
- Script placement: why the `<script>` tag sits at the bottom
