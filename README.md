## 🧭 About this repository

This is the full **higher-level programming curriculum** in one repo. It
starts with the smallest possible programs (is this number positive?) and
climbs all the way to server-side rendering, object-relational mapping and
a hand-rolled RESTful API.

Every folder is one project, and every project has its own **README with
concepts, task-by-task file descriptions, requirements and runnable
examples** — dive into whichever layer interests you:

## 📚 The journey

**Level 1 — the language core**

| Project | What it covers |
|---|---|
| [`python-if_else_loops_functions/`](python-if_else_loops_functions/README.md) | Branching, loops, functions — where scripts become programs |
| [`python-import_modules/`](python-import_modules/README.md) | Modules, imports, `sys.argv` and bytecode disassembly |
| [`python-data_structures/`](python-data_structures/README.md) | Lists & tuples — indexing, slicing, swapping |
| [`python-more_data_structures/`](python-more_data_structures/README.md) | Sets, dictionaries, `map`/`lambda` — and Roman numerals |
| [`python-exceptions/`](python-exceptions/README.md) | try / except / finally — failing gracefully |
| [`python-test_driven_development/`](python-test_driven_development/README.md) | Tests first, code second: doctest & unittest |

**Level 2 — objects everywhere**

| Project | What it covers |
|---|---|
| [`python-classes/`](python-classes/README.md) | Your first custom types — a Square that draws itself |
| [`python-more_classes/`](python-more_classes/README.md) | The perfected Rectangle, dunder methods & N-Queens |
| [`python-inheritance/`](python-inheritance/README.md) | BaseGeometry → Rectangle → Square, and a rebellious MyInt |
| [`python-everything_is_object/`](python-everything_is_object/README.md) | The philosophy exam: identity vs equality, 28 answers |
| [`python-abc/`](python-abc/README.md) | Abstract base classes, duck typing, multiple inheritance |

**Level 3 — data in & data out**

| Project | What it covers |
|---|---|
| [`python-input_output/`](python-input_output/README.md) | Files, JSON round-trips and log parsing |
| [`python-serialization/`](python-serialization/README.md) | pickle, CSV, XML — and shipping bytes over sockets |
| [`SQL_introduction/`](SQL_introduction/README.md) | CREATE, SELECT, INSERT — the first database |
| [`SQL_more_queries/`](SQL_more_queries/README.md) | JOINs, subqueries, privileges and a TV-show database |
| [`python-object_relational_mapping/`](python-object_relational_mapping/README.md) | SQLAlchemy: classes become tables |

**Level 4 — the web**

| Project | What it covers |
|---|---|
| [`javascript-warm_up/`](javascript-warm_up/README.md) | Node.js fundamentals — console.log to callbacks |

## 🛠️ Environment

- Ubuntu 20.04 LTS · `python3` (3.8.x) · Node.js 14 · MySQL 8.0
- Python style: **pycodestyle** (PEP 8) · JS style: **semistandard**
- Each project folder lists its exact requirements in its own README
