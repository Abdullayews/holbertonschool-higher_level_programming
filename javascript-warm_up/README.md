## 📖 About this project

The first JavaScript project — and the first time the terminal, not the
browser, is home. Running on **Node.js**, this set warms up the language
fundamentals: printing with `console.log`, reading `process.argv`, casting
with `parseInt`, loops, functions, objects — and by the end, callbacks and
mutating a global from inside a function.

The classic moment: `const` vs `let` — one task lets a `let_me_const`
variable teach exactly why reassignment is the difference.

## 🎯 Concepts covered

- `console.log()` — and `.length` of printed values
- `process.argv` — arguments on the command line
- `parseInt()` / `isNaN()` — number coercion with guard rails
- `const` vs `let` — immutability of the binding
- Functions, closures and first-class values
- Objects: properties, methods, mutation
- Callbacks — passing behavior around
